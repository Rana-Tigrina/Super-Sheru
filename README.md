# 🐅 Super Sheru Bros (सुपर शेरू)

> Super Mario inspired platformer — eight lands of Bharat. Powered by GRD v2 fixed-step physics and machine-proven levels.

## ⚡ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/your-username/Super-Sheru.git
cd Super-Sheru

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🛠️ Commands

- `npm run dev` — Start Vite local dev server
- `npm run build` — Build for production (runs asset palette & level proof gates)
- `npm run preview` — Preview production build locally
- `npm test` — Run physics & level test suite
- `npm run palette` — Validate art sprite palette rules
- `npm run prove` — Run level solver proofs
